# About Syncfusion® WPF ChromelessWindow Control

ChromelessWindow is used to create customizable windows for the end user's applications. With these windows, the user has complete control over the entire window. The features offered include resizing, dragging, and moving the window. It also implements several other features to present an appealing user interface to the end users. It supports various built-in skins and lets the user control its behavior and appearance. The features are described in detail in the further topics.
