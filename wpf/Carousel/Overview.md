# About Syncfusion® WPF Carousel Control

The [WPF Carousel](https://www.syncfusion.com/wpf-controls/carousel) is a circular conveyor on which objects are displayed and rotated. The `Carousel` control provides a `3D` interface for displaying objects with interactive navigation, Data Binding Path, ItemsPerPage, Scaling and Skewing.

## Features

* Data Binding support
* Path support
* ItemsPerPage support
* Scaling and Skewing support
* Rotation support
* Opacity support
