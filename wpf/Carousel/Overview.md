# About Syncfusion® WPF Carousel Control

The [WPF Carousel](https://help.syncfusion.com/cr/wpf/Syncfusion.Windows.Shared.Carousel.html) is a circular conveyor used on which objects are displayed and rotated. The `WPF Carousel` control provides a `3D` interface for displaying objects with interactive navigation, Data Binding Path, ItemsPerPage, Scaling and Skewing.

## Features

* Data Binding support
* Path support
* ItemsPerPage support
* Scaling and Skewing support
* Rotation support
* Opacity support
