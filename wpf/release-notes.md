# Syncfusion WPF AI Coding Assistants Release Notes

This document provides information about the changes and new features included in each version of the Syncfusion WPF AI Coding Assistants, including the [Syncfusion.WPF.MCP](https://www.nuget.org/packages/Syncfusion.WPF.MCP) MCP Server, Skills, Agentic UI Builder and so on.

## MCP Server

**(v1.0.0) - July 31, 2026**

**Breaking Changes**

- The [@syncfusion/wpf-assistant](https://www.npmjs.com/package/@syncfusion/wpf-assistant) npm package has been migrated to the [Syncfusion.WPF.MCP](https://www.nuget.org/packages/Syncfusion.WPF.MCP) .NET package. As part of this transition, [@syncfusion/wpf-assistant](https://www.npmjs.com/package/@syncfusion/wpf-assistant) package has been deprecated and will no longer receive updates.

- The coding assistant tool identifier has been changed from **`#SyncfusionWPFAssistant`** to **`search_docs`** for a better naming convention.
