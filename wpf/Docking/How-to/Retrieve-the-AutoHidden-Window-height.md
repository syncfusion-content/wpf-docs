# How to retrieve AutoHidden Window height in Docking in WPF 

EndDockHeaderHeight is the property that is used to retrieve the AutoHidden Window height.

{% highlight xaml %}

double height = DockingManager.EndDockHeaderHeight;

{% endhighlight %}
